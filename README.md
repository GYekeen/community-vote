# Community Vote Contract

A decentralized voting contract that allows community members to create
proposals and participate in governance decisions directly on-chain.

## Key Functions
- `create-proposal` — Submit a new community decision proposal
- `vote` — Cast a vote on an active proposal
- `close-proposal` — Finalize voting and lock results
- `get-proposal` — View proposal details and current status
- `has-voted` — Ensure single vote per address

Suitable for community DAOs, protocol signaling, grants selection, and public
decision processes.
